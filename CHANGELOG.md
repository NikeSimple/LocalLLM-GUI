# Изменения

## v0.1.0 — первая рабочая версия

### Реализовано
- Трёхпанельный интерфейс (диалоги / чат / настройки)
- Интеграция с Ollama через ApiClient (QNetworkAccessManager)
- Стриминг ответов модели в чат
- Светлая и тёмная темы с переключением
- Прикрепление файлов (TXT, MD, LOG, код)
- Автозапуск Ollama при старте приложения
- Автоматическое название диалогов через модель
- Сворачивание левой и правой панелей

### Соответствие ТЗ
- FR-01, FR-02 — список и переключение моделей
- FR-05 — стриминг сообщений
- FR-06 — история диалога
- FR-11 — системный промпт
- FR-14, FR-15 — прикрепление файлов
- FR-17 — параметры генерации
- FR-19 — разделение интерфейса на панели
