Общее описание
--------------

**LocalLLM-GUI** — десктопное приложение для работы с локальными
языковыми моделями через Ollama. Поддерживает:

- выбор и переключение моделей без перезапуска;
- стриминг ответов модели в чат;
- сохранение истории диалогов в SQLite;
- систему шаблонов промптов с чекбоксами;
- экспорт диалогов в JSON;
- 4 темы оформления.

**Стек:** C++17, Qt 6 (Widgets, Network, Sql, Svg), SQLite3, CMake, Git, GitHub Actions.
