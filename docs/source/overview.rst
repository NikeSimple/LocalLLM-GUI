Обзор проекта
=============

Назначение
----------

Приложение автоматизирует работу с локальными LLM через Ollama:
генерация текста, анализ документов, ведение диалогов.

Целевая аудитория
-----------------

- Студенты и исследователи;
- Разработчики;
- Специалисты с конфиденциальными данными;
- Энтузиасты локальных LLM.
