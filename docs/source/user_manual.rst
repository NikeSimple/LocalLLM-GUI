Руководство пользователя
========================

Установка
---------

1. Установите MSYS2 UCRT64 и зависимости (см. README).
2. Установите Ollama с https://ollama.com/download.
3. Скачайте модель: ``ollama pull llama3.1:8b``.
4. Соберите проект:

.. code-block:: bash

   mkdir build && cd build
   cmake .. -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=/ucrt64
   cmake --build .

Запуск
------

Запустите ``LocalLLM-GUI.exe`` из папки ``build/``.

Основные функции
----------------

**Работа с диалогами:**

- Создать диалог — кнопка «Новый диалог» в левой панели;
- Удалить — кнопка ⋮ → «Удалить»;
- Экспортировать в JSON — кнопка ⋮ → «Экспортировать».

**Шаблоны промптов:**

1. Настройки → Шаблоны;
2. Создайте шаблон, введите текст;
3. Отметьте галочкой активные шаблоны;
4. Тексты активных шаблонов объединяются в поле «Инструкция для модели».

**Горячие клавиши:**

- **Ctrl+Enter** — отправить сообщение;
- **Ctrl+N** — новый диалог.
