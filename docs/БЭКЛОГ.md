## 1. Известные ограничения

Функции, заявленные в исходном ТЗ, но не реализованные в v1.0.0.
Перенесены в план развития.

| ID | Ограничение | Причина | Приоритет |
|----|-------------|---------|-----------|
| LIM-01 | PDF-файлы не парсятся | Требуется библиотека PoDoFo или pdfium, не входит в стандартный MSYS2 UCRT64 | Средний |
| LIM-02 | DOCX-файлы не парсятся | Требуется libzip + pugixml, установка через pacman затруднена | Средний |
| LIM-03 | Нет переключения между Ollama и llama.cpp | Паттерн Strategy не реализован | Средний |
| LIM-04 | Общий системный промпт для всех диалогов | Нет отдельного промпта per-dialog | Низкий |
| LIM-05 | Индикатор генерации без анимации | Реализован только текстовый статус | Низкий |
| LIM-06 | Интерфейс только на русском | Английская локализация не реализована | Низкий |
| LIM-07 | Нет облачных моделей Ollama | Приложение работает только локально | Высокий |
| LIM-08 | Нет веб-поиска | Требуется API-ключ Ollama Cloud | Низкий |

## 5. Как предложить улучшение

1. Открыть репозиторий: https://github.com/NikeSimple/LocalLLM-GUI
2. Перейти во вкладку **Issues**
3. Нажать **New issue**
4. Описать улучшение по шаблону:
   - Что нужно
   - Зачем (проблема, которую решает)
   - Как проверить результат

---

## 6. Приоритеты

- **Высокий** — критично для развития продукта, делаем в первую очередь.
- **Средний** — полезно, но не блокирует работу.
- **Низкий** — nice-to-have, откладываем на потом.
