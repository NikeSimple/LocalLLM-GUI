# LocalLLM-GUI

Локальный GUI-клиент для работы с нейросетями (Ollama).

## Описание

Десктопное приложение на **C++17 / Qt 6** для работы с локальными текстовыми LLM:
выбор модели, системные промпты, история диалогов, прикрепление файлов, экспорт в JSON.

Всё работает **локально** — данные не покидают устройство.

- **FR-01** — просмотр списка моделей
- **FR-02** — переключение моделей без перезапуска
- **FR-03** — указание URL сервера
- **FR-04** — статус подключения
- **FR-05** — отправка сообщений со стримингом
- **FR-06** — история текущего диалога
- **FR-07** — сохранение диалогов в SQLite
- **FR-08** — просмотр и загрузка диалогов
- **FR-09** — удаление диалогов
- **FR-10** — экспорт в JSON
- **FR-11** — системный промпт
- **FR-12** — шаблоны промптов с чекбоксами
- **FR-14** — загрузка файлов (TXT, MD, код)
- **FR-15** — список загруженных файлов
- **FR-17** — параметры генерации (temperature, top-p, max tokens)
- **FR-18** — сброс параметров
- **FR-19** — разделение интерфейса на панели

## Установка

### 1. Установка MSYS2 и зависимостей

Скачайте MSYS2 с https://www.msys2.org/ и установите. Откройте терминал **MSYS2 UCRT64** (не MSYS2 MSYS, не MINGW64) и выполните:

```bash
pacman -S mingw-w64-ucrt-x86_64-gcc
pacman -S mingw-w64-ucrt-x86_64-cmake
pacman -S mingw-w64-ucrt-x86_64-qt6-base
pacman -S mingw-w64-ucrt-x86_64-qt6-svg
pacman -S mingw-w64-ucrt-x86_64-sqlite3
```

### 2. Установка Ollama

Ollama — это локальный сервер, который запускает LLM-модели на вашем компьютере.

**Скачать:** https://ollama.com/download

**Windows:** скачайте `OllamaSetup.exe`, запустите установку, дождитесь окончания. После установки Ollama запустится автоматически и будет доступна по адресу `http://localhost:11434`.

**Проверка:** откройте браузер и перейдите на http://localhost:11434 — должна появиться надпись `Ollama is running`.

### 3. Скачивание локальной модели

Модели скачиваются через командную строку. Откройте **cmd** или **PowerShell** и выполните:

```bash
ollama pull llama3.1:8b
```

Это скачает модель `llama3.1:8b` (~5 ГБ). На RTX 4060 Laptop с 8 ГБ VRAM она работает комфортно.

**Другие популярные модели:**

| Модель | Размер | Назначение |
|--------|--------|------------|
| `llama3.1:8b` | ~5 ГБ | Универсальная, хороший русский |
| `qwen2.5:7b` | ~4.5 ГБ | Хороша для кода и русского |
| `mistral:7b` | ~4 ГБ | Быстрая, лёгкая |
| `gemma2:9b` | ~5.5 ГБ | От Google, качественные ответы |
| `phi3:mini` | ~2 ГБ | Маленькая, для слабых ПК |

**Проверить, какие модели уже скачаны:**

```bash
ollama list
```

**Удалить ненужную модель:**

```bash
ollama rm имя_модели
```

### 4. Сборка проекта

```bash
cd LocalLLM-GUI
mkdir build && cd build
cmake .. -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=/ucrt64
cmake --build .
./LocalLLM-GUI.exe
```

## Использование

1. Убедитесь, что **Ollama** запущена (значок в системном трее Windows).
2. Запустите `LocalLLM-GUI.exe`.
3. В правой панели выберите модель из списка.
4. Введите сообщение в поле ввода и нажмите **Ctrl+Enter** или кнопку отправки.
5. Для прикрепления файла нажмите иконку скрепки — поддерживаются TXT, MD, LOG, JSON, CSV и файлы кода.

### Горячие клавиши

- **Ctrl+Enter** — отправить сообщение
- **Ctrl+N** — новый диалог

### Управление диалогами

- **Создать** — кнопка «Новый диалог» в левой панели.
- **Удалить** — кнопка **⋮** справа от диалога → «Удалить».
- **Экспортировать** — кнопка **⋮** → «Экспортировать» (JSON).

### Шаблоны промптов

1. Откройте **Настройки → Шаблоны**.
2. Создайте шаблон, введите текст (можно многострочный).
3. Отметьте галочкой шаблоны, которые должны быть активны.
4. Тексты активных шаблонов автоматически объединяются в поле **«Инструкция для модели»** в правой панели.

## Устранение неполадок (Troubleshooting)

### Приложение не запускается — ошибка про libgcc_s_seh-1.dll / libstdc++-6.dll / Qt6Core.dll

**Причина:** Windows не находит DLL-библиотеки Qt и MinGW, потому что они лежат в `C:\msys64\ucrt64\bin`, а этот путь не в `PATH`.

**Решение (одно из трёх):**

1. **Запускать через MSYS2 UCRT64** — откройте терминал MSYS2 UCRT64, перейдите в папку с `.exe` и запустите:
   ```bash
   cd /c/Users/kopty/OneDrive/Desktop/LocalLLM-GUI/build
   ./LocalLLM-GUI.exe
   ```

2. **Добавить в PATH:**
   - Win+R → `sysdm.cpl` → Дополнительно → Переменные среды.
   - В `Path` добавь `C:\msys64\ucrt64\bin`.
   - Перезапусти Проводник или перезагрузись.

3. **Собрать портативную версию через `windeployqt`:**
   ```bash
   cd /c/Users/kopty/Desktop
   mkdir LocalLLM-GUI-Portable
   cp /c/Users/kopty/OneDrive/Desktop/LocalLLM-GUI/build/LocalLLM-GUI.exe LocalLLM-GUI-Portable/
   cd LocalLLM-GUI-Portable
   /c/msys64/ucrt64/bin/windeployqt.exe LocalLLM-GUI.exe
   ```
   Рядом с `.exe` появятся все нужные DLL. Папку можно переносить на другой ПК.

### Ошибка «Не удалось подключиться к Ollama» / статус «Не подключено»

**Причина:** Ollama не запущена, либо запущена на другом порту.

**Решение:**
1. Проверь, что Ollama запущена — значок в системном трее Windows.
2. Открой в браузере http://localhost:11434 — должна быть надпись `Ollama is running`.
3. Если нет — запусти Ollama вручную: Пуск → Ollama.
4. Если Ollama на другом порту — открой **Настройки → Сервер** в приложении и укажи правильный URL.

### Модель не появляется в списке

**Причина:** в Ollama не скачано ни одной модели.

**Решение:**
```bash
ollama list          # проверить, что есть
ollama pull llama3.1:8b   # скачать модель
```

После скачивания перезапусти приложение — список моделей обновится автоматически.

### Приложение падает при старте

**Причина:** возможно, повреждён файл БД `localllm.db`, или не хватает прав на запись.

**Решение:**
1. Проверь, что файл `localllm.db` есть в корне проекта: `LocalLLM-GUI/localllm.db`.
2. Если файла нет или он 0 байт — удали и перезапусти приложение, оно создаст заново:
   ```bash
   rm localllm.db
   ```
3. Если не помогает — запусти из терминала MSYS2, чтобы увидеть сообщение об ошибке:
   ```bash
   cd build
   ./LocalLLM-GUI.exe
   ```

### Диалоги пропадают после пересборки

**Причина:** если БД лежит внутри `build/`, то команда `rm -rf build` её удаляет.

**Решение:** в текущей версии БД уже хранится в корне проекта (`LocalLLM-GUI/localllm.db`), поэтому пересборка её не затрагивает. Если у тебя старая версия — обнови `main_window.cpp`, путь к БД должен быть:
```cpp
QString dbPath = QDir::current().absoluteFilePath("../localllm.db");
```

### Шаблоны промптов не объединяются

**Причина:** не отмечены галочки.

**Решение:**
1. **Настройки → Шаблоны**.
2. Поставь галочку слева от нужных шаблонов.
3. Тексты активных шаблонов появятся в поле **«Инструкция для модели»** в правой панели, разделённые `---`.

Если после перезапуска галочки сбросились — проверь, что поле `is_template` в таблице `prompts` обновляется (приложение должно сохранять состояние).

### Кракозябры в консоли вместо русских букв

**Причина:** Windows-консоль по умолчанию работает в CP866, а приложение пишет в UTF-8.

**Решение:** уже исправлено в `main.cpp` и `tests/test_main.cpp` — добавлен вызов `SetConsoleOutputCP(CP_UTF8)`. Если кракозябры остались — убедись, что у тебя последняя версия кода:
```bash
grep -n "SetConsoleOutputCP" main.cpp tests/test_main.cpp
```

### Сборка падает с ошибкой «файл не найден»

**Причина:** возможно, ты удалил какой-то `.cpp` файл, но он всё ещё в `CMakeLists.txt`.

**Решение:**
1. Проверь, что все файлы из `set(SOURCES ...)` реально существуют.
2. Пересобери с нуля:
   ```bash
   rm -rf build
   mkdir build && cd build
   cmake .. -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=/ucrt64
   cmake --build .
   ```

## CI/CD

Проект использует **GitHub Actions** для автоматической сборки и тестирования. Файл `.github/workflows/build.yml` запускает:
- Установку Qt 6 и SQLite на Ubuntu
- Конфигурацию через CMake
- Сборку проекта
- Прогон всех тестов

При каждом `git push` результаты видны на вкладке **Actions** в репозитории GitHub: https://github.com/NikeSimple/LocalLLM-GUI/actions
