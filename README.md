# LocalLLM-GUI

Локальный GUI-клиент для работы с нейросетями (Ollama / llama.cpp).

## Описание

Десктопное приложение на **C++17 / Qt 6** для работы с локальными текстовыми LLM:
выбор модели, системные промпты, история диалогов, прикрепление файлов, экспорт в JSON.

Всё работает **локально** — данные не покидают устройство.

## Соответствие ТЗ

- **FR-01** — просмотр списка моделей
- **FR-02** — переключение моделей без перезапуска
- **FR-03** — указание URL сервера
- **FR-04** — статус подключения
- **FR-05** — отправка сообщений со стримингом
- **FR-06** — история текущего диалога
- **FR-07** — сохранение диалогов в SQLite
- **FR-08** — просмотр и загрузка диалогов
- **FR-09** — удаление диалогов
- **FR-10** — экспорт в JSON
- **FR-11** — системный промпт
- **FR-12** — шаблоны промптов
- **FR-14** — загрузка файлов (TXT, MD, код)
- **FR-15** — список загруженных файлов
- **FR-17** — параметры генерации (temperature, top-p, max tokens)
- **FR-18** — сброс параметров
- **FR-19** — разделение интерфейса на панели

## Технологии

| Компонент | Назначение |
|-----------|------------|
| **C++17** | Язык разработки |
| **Qt 6** | GUI (Widgets), сеть, SQL |
| **CMake** | Система сборки |
| **SQLite3** | Локальная база данных |
| **Ollama API** | HTTP-интерфейс к LLM |
| **nlohmann/json** | Работа с JSON |
| **libcurl** | HTTP-запросы (опционально) |

## Требования

- **ОС:** Windows 10/11
- **Среда сборки:** MSYS2 UCRT64 с Qt 6
- **Ollama:** запущена локально (`http://localhost:11434`)
- **ОЗУ:** минимум 8 ГБ
- **Диск:** 10 ГБ свободного места
